# Salman Khan — Developer Portfolio

A responsive single-page developer portfolio built with Vue 3, Vite and Lucide icons. The design uses custom CSS and adapts to mobile, tablet and desktop screens.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```
